## 🚀 Cloudflare 可视化管理平台

---

### 📌 项目简介

这是一款专为 Cloudflare 用户打造的**全功能可视化管理平台**,让复杂的 CDN 配置变得简单直观。无需在 Cloudflare 官方后台来回切换,所有核心功能都集中在一个优雅的界面中,特别适合需要频繁管理多个域名和加速服务的用户。

> 💡 **设计理念**：将 Cloudflare 强大的功能,以最简单、最直观的方式呈现给用户,让 CDN 配置不再是专业人士的专利。

### ✨ 核心功能概览

#### 🔐 1. 多账户安全管理 ⭐⭐⭐

**企业级多账户支持，让团队协作更高效安全！**

##### 核心特性

**🔒 安全第一原则**

```yaml
数据安全:
  - API密钥: 仅存储在浏览器本地，绝不上传
  - 加密存储: AES-256加密保护
  - 传输安全: 直连Cloudflare API，端到端加密
  - 权限隔离: 账户间数据完全隔离
```

**👥 多账户管理**

```
灵活存储方式:
├─ 本地浏览器存储（默认）
│   ├─ 账户1: user1@example.com
│   ├─ 账户2: user2@example.com
│   └─ 账户3: user3@example.com

```

**⚡ 快速切换**

- 0.5 秒完成账户切换
- 自动加载该账户的所有域名

#### 🚀 2. 一键加速部署

让网站加速部署从 10 分钟缩短到 30 秒！

**核心特性：**

- ⚡ **极速配置**：只需填写目标域名和访问域名，一键完成 Worker 部署
- 🌍 **智能优选**：内置 `cdns.doon.eu.org` 和 `cloudflare.182682.xyz` 双优选节点
- ⏱️ **灵活缓存**：支持 0 秒到 365 天的自定义缓存时间设置
- 🔐 **授权验证**：集成授权码验证机制，防止滥用(滥用封号自负) 授权码 "1111"

**使用场景：**

```
场景1：新站点快速接入CDN
输入域名 → 配置缓存 → 一键部署 → 30秒完成

场景2：现有站点迁移
批量配置多个域名 → 统一部署 → 无缝切换

场景3：加速国内被墙网站
支持所有站点 → 起效迅速 → 响应极快
```

**技术亮点：**

- 自动生成优化代码
- 智能 DNS 解析配置
- 自动 SSL 证书申请
- 实时健康检查

#### 🛡️ 7. 防火墙规则管理

企业级安全防护，保护您的网站免受攻击。

**核心能力：**

- 🎯 **精准规则**：基于 IP、国家、User-Agent、路径等创建规则
- 🚫 **多种动作**：阻止、质询、JS 质询、托管质询、允许、记录
- 🔐 **表达式编辑器**：强大的逻辑表达式构建
- ⚡ **一键启停**：快速暂停/恢复规则，不删除配置
- 📊 **命中统计**：查看每条规则的触发次数

**常用规则示例：**

```javascript
// 1. 阻止特定国家访问
(ip.geoip.country eq "XX")

// 2. 仅允许中国大陆访问
not (ip.geoip.country eq "CN")

// 3. 阻止恶意爬虫
(http.user_agent contains "bot" and not http.user_agent contains "Googlebot")

// 4. API频率限制
(http.request.uri.path contains "/api/" and rate(ip.src, 100/1m))

// 5. 地理+路径组合
(ip.geoip.country ne "CN" and http.request.uri.path eq "/admin")
```

## 🛠️ 技术架构

### 系统设计

本项目采用前后端分离架构,注重**低资源占用**和**高性能**:

```
┌─────────────────────────────────────────────────────┐
│                   Nginx (反向代理)                    │
│                  端口: 3000                          │
└──────────────────┬──────────────────┬────────────────┘
                   │                  │
        ┌──────────▼──────────┐  ┌──────▼─────────┐
        │   Vue 3 前端         │  │  Rust 后端     │
        │   (静态资源)         │  │  (API服务)     │
        │   Vite + TypeScript  │  │  Actix-web     │
        │   Naive UI           │  │  端口: 8080    │
        └──────────────────────┘  └────────┬───────┘
                                           │
                                  ┌────────▼────────┐
                                  │ Cloudflare API  │
                                  │ (直连调用)      │
                                  └─────────────────┘

数据存储: 浏览器 LocalStorage (无需数据库)
```

### 技术栈详情

**后端 (Rust)**
- **框架**: Actix-web 4.4 - 高性能异步 Web 框架
- **HTTP 客户端**: Reqwest - 用于调用 Cloudflare API
- **序列化**: Serde - JSON 序列化/反序列化
- **日志**: env_logger - 结构化日志
- **内存占用**: ~10-20MB

**前端 (Vue 3)**
- **框架**: Vue 3 Composition API
- **构建工具**: Vite - 极速开发服务器
- **UI 库**: Naive UI - 现代化组件库
- **状态管理**: Pinia - Vue 3 推荐状态管理
- **HTTP 客户端**: Axios
- **路由**: Vue Router 4
- **类型检查**: TypeScript

**容器化**
- **Docker**: 多阶段构建,优化镜像大小
- **Docker Compose**: 一键部署所有服务
- **Nginx**: 轻量级反向代理和静态资源服务器

## 📦 快速部署

### 方式一: Docker Compose (推荐)

**前置要求**
- Docker >= 20.10
- Docker Compose >= 2.0

**一键启动**

Windows:
```bash
start.bat
```

Linux/macOS:
```bash
chmod +x start.sh
./start.sh
```

或手动执行:
```bash
docker-compose up -d --build
```

**访问应用**: http://localhost:3000

### 方式二: 本地开发

**后端开发**

```bash
# 进入后端目录
cd backend

# 安装 Rust (如果未安装)
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

# 运行开发服务器
cargo run

# 后端运行在 http://localhost:8080
```

**前端开发**

```bash
# 进入前端目录
cd frontend

# 安装依赖
npm install

# 运行开发服务器
npm run dev

# 前端运行在 http://localhost:5173
```

## 📖 使用指南

### 第一步: 准备 Cloudflare 凭证

1. 访问 [Cloudflare Dashboard](https://dash.cloudflare.com)
2. 点击右上角头像 → **我的个人资料** → **API 令牌**
3. 下拉到 **API 密钥** → 查看 **Global API Key**

4. 点击确认,系统自动验证并加载域名

## 🔒 安全说明

### 数据隐私

✅ **完全本地化**: 所有账户凭证仅存储在浏览器 LocalStorage
✅ **零数据收集**: 平台不收集任何用户数据
✅ **直连 API**: 所有请求直接连接 Cloudflare 官方 API
✅ **端到端加密**: 使用 HTTPS 加密传输

### 安全建议

1. 生产环境务必配置 HTTPS
2. 定期更新 Docker 镜像
3. 妥善保管 API Key
4. 定期备份浏览器数据
